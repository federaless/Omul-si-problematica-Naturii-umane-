# Omul și problematica naturii umane

Proiect realizat de **Doroftei Federico Mario** la disciplina filosofie, clasa a XII-a A.

Site cu temă filosofică despre lecția „Omul și problematica naturii umane”: ideile principale (Protagoras, Aristotel, Pascal, Kant, Sartre, Lucian Blaga), o galerie de opere de artă și trei teme de dezbatere pentru clasă.

**Site-ul online:** https://federaless.github.io/Omul-si-problematica-Naturii-umane-/

## Cum se deschide

- Online, la adresa de mai sus.
- Local: descarcă `index.html` și deschide-l în browser. Imaginile se încarcă de pe Wikimedia Commons, așa că e nevoie de internet; fonturile sunt incluse în fișier.
